# 寺院サイトのデザイン刷新

2026年10月26日。深紫と金による華やかな導入から、写真鑑賞、教えへの関心、家族・ご先祖の記憶へ進む画面を実装。

## 構成

- `src/styles/splendor.css`：既存の共通スタイル・discoveryの後に読み込む共通デザイン。明朝体はOSのフォントを使用し、追加のWebフォント通信を発生させない。
- `public/assets/brand/golden-clouds.svg`：独自の装飾用金雲。寺紋・宗派紋を転用していない。
- ブランドマーク・favicon・manifestの配色を深紫と金に統一。
- トップ：ヒーロー写真を遮らない左右構成、既存6件を3列×2段で表示。小画面では順に写真・文章を表示し、6件すべてを縦に閲覧できる。
- `ReflectionPassage.astro`：教えを知る入口と家族の記憶をたどる導入。トップと寺院詳細で共有。文章は編集上の問いかけであり、寺院固有の由緒や教義を創作していない。
- 詳細：既存代表写真の大きな表示と拡大ボタンを前方に追加。既存ギャラリー・解説・出典を残す。
- 寺社読み物：既存写真付きの案内と、生成り色の読みやすい本文面。
- ランキング・地域・検索・基礎資料等にも共通の配色と文字組みを適用。

## 維持するもの

登録118件、ヒーロー7枚、ピックアップ6件。ピックアップのプール・固定枠・抽選方法、一覧・地区・関連寺院の選出と件数、写真レジストリ、個々の写真説明・出典、実アクセスの集計・順位・更新方法は変更していない。

写真の拡大、Escapeで閉じる、フォーカスの復元、既存ハッシュによる台帳展開を継続。動きの軽減設定に対応。

## 検証の範囲

`npm run check`、`node scripts/validate-discovery.mjs`、改修前ビルドとの比較を実施。比較スクリプトと詳細な記録は作業用フォルダに保存。

PC、390pxフレームのトップ・詳細・読み物・ランキング、320pxフレームの検索、768pxフレームの地区一覧を実ブラウザで確認。フレームには縦スクロールバー幅を含むため、390pxフレームの実コンテンツ幅は375px。

公開後の滞在時間の効果は、この実装検証だけでは判定しない。既存の有効閲覧時間、写真拡大、記事間遷移の計測で確認する。
