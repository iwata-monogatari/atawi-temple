# 寺院写真取り込みルール

## 目的
寺院写真を短時間で安全にページへ反映し、主写真の誤選定・画像欠落・既存データの上書きを防ぐ。

## 主写真の選定順
1. 本堂の正面または堂宇全体が分かる写真
2. 本堂の外観が分かる別角度
3. 山門・入口
4. 境内全景

案内板、石碑、墓地、樹木だけの写真、極端な接写は主写真にしない。目視で本堂を確認できない場合は、既存の主写真を変更せず、写真をギャラリーへ登録して保留する。

## 取り込み手順
- 対象フォルダの画像枚数と合計容量を確認する。
- `public/assets/temples/<slug>/` に原本をコピーし、既存ファイルを削除・上書きしない。
- `data/temple-media.json` の `hero_image` は `photos` 内の1枚を指定する。主写真を指定した場合、その写真を `photos` の先頭にも置き、`category_id` は `main-building` にする。
- ファイル名から内容を推測せず、確認できた事実だけを `alt` と `caption` に書く。判断できない写真は番号付きの汎用説明にする。

## 5分の時間配分
- 0〜1分: フォルダ・枚数・対象slugを確認
- 1〜2分: 画像をコピーし、本堂候補を目視選定
- 2〜3分: `hero_image` と写真メタデータを登録
- 3〜4分: `npm run validate:data` と `npm run build`
- 4〜5分: `dist` をCloudflare Pagesの本番へ公開

## 公開前チェック
- `hero_image` のファイルが存在する
- 取り込み枚数とページ内画像参照数が一致する
- `npm run validate:data` が成功する
- `npm run build` が成功する
- 既存の未コミット変更を削除・巻き戻ししていない
