# 更新情報の生成

トップページ、`/updates/latest.json`、`/updates/` は `src/lib/updates.ts` の共通フィードを使う。

- 寺院・研究の既存記録に `data/blog-posts.json` のブログを自動で加える。
- ブログは記事ごとに1件。公開日 `published` と最終更新日 `updated` の新しい方で日付順に並ぶ。
- `updated` が `published` より新しいときだけ「更新しました」と表示する。初出日は変更しない。
- トップとJSONは新着5件、更新一覧は6件目以降。寺院・研究の過去記録を維持する。
- 通常のブログ台帳更新、build、公開で反映されるため、更新情報への手動転記は不要。
- ブログの `cover` を日付の下の縮小画像として表示する。画像なしの記事は日付のみ。トップの静的HTML・JSONによる再描画・6件目以降の一覧で同じ画像を使用する。
- `npm run validate:build` で日付、重複、並び順、HTML/JSONの一致、5件の分割境界と遷移先を検査する。
