# 更新情報の統合

トップの新着5件、`/updates/latest.json`、`/updates/`は、`src/lib/updates.ts`が生成する同一の更新一覧を使用する。

寺院・研究等の既存更新台帳に、`data/blog-posts.json`の各記事を自動で加える。ブログ記事は1記事につき1件の通知とし、公開日と最終更新日の新しい方で並べる。最終更新日が公開日より後なら「更新しました」、それ以外は「公開しました」と表示する。既存の寺院・研究の通知は保持し、同日の既存通知の順番も保つ。

ブログの新規公開・改稿時は、従来どおり記事台帳の `published` / `updated` を正しく設定してサイトをビルド・公開する。更新用台帳にブログの通知を手作業で二重登録する必要はない。公開済み静的サイトが、台帳の変更やビルドなしで記事本文の変更を検出する仕組みではない。

トップとJSONは先頭5件、6件目以降の一覧は残りを掲載する。JavaScriptが使えない場合もトップの静的HTMLに同じ5件が存在する。

検証：`npm run build` 後に `node scripts/test-update-feed.mjs` を実行。新規公開、再更新、未設定・逆転した更新日、並び順、全記事の包含、3出力の一致と分割境界、記事リンクの実在を確認する。
