# ATAWI temple 寺院ページ作成ルール

国分寺ページを初期モデルとして、寺院ページの情報密度を段階的に上げるためのルールです。

## ページ構成

1. 基本情報
   - 寺院名、読み方、住所、地区、宗派、状態、有人・無人、御朱印、最終確認日を掲載する。
2. 写真ギャラリー
   - まず主写真を1枚置く。
   - その下に分類済み写真を並べる。
   - 写真は事実確認に使えるよう、説明板・石標・堂宇・境内全景を優先する。
3. 掲載内容
   - 公式名簿の基礎情報と、現地確認・公的資料で確認できた情報を分けて書く。
4. 史跡・文化財情報
   - 国・県・市指定文化財、史跡、説明板、発掘調査情報がある場合のみ掲載する。
5. 出典・参考資料
   - 行政資料、文化財データベース、現地説明板、現地写真の順に整理する。
6. 情報提供・訂正
   - 写真、読み方、由緒、掲載不可の要望を受け付ける。

## 写真分類

| 分類 | 用途 |
|---|---|
| 本堂・堂宇 | ページ主写真、建物の把握 |
| 境内全景 | 参拝動線、敷地の雰囲気 |
| 入口・石標 | 所在確認、ページ冒頭の補助 |
| 説明板・案内板 | 由緒・文化財情報の根拠 |
| 石造物・手水 | 境内遺物、年代銘、地域史 |
| 地図・札所案内 | 周辺寺院・霊場との接続 |
| その他 | 補助写真 |

## 掲載判断

- 人の顔、車のナンバー、個人宅内部、墓石の個人名が大きく写る写真は公開前に確認する。
- 由緒や伝承は、断定せず「現地説明板によれば」「資料では」と出典を添える。
- 寺院の公式サイトではないため、参拝可否、御朱印、法要、檀家情報は確認済みの場合のみ掲載する。
- 文化財・史跡は、寺院そのものと史跡範囲が異なる場合があるため、本文で区別する。

## 管理者の写真登録からページ化まで

1. 管理者がCloudflare Accessでログインする。
2. 管理画面で全寺院から掲載先を選び、写真をアップロードする。
3. 管理画面で写真分類の候補を確認する。
4. Cloudflare R2に写真とメタデータを保存する。
5. 個人情報・掲載可否・分類を確認する。
6. 掲載用WebPへ変換し、`data/temple-media.json`へ登録する。
7. 必要に応じて寺院本文、出典、現地確認日を更新する。

写真管理画面は公開ページからリンクせず、`/admin/photos/`をCloudflare Accessで保護する。
