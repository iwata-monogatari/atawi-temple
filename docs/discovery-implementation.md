# 寺院の滞在時間向上改修

2026-10-26。登録118件と既存の寺院カード選出条件を維持する。

## 実装

- `DiscoveryPhotos`: 既存写真からカテゴリーの異なる最大6枚を前方に配置。全写真は既存の記録欄にも保持。拡大・Escape・閉じた後のフォーカス復元に対応。
- `DiscoveryIntro`: 各寺院の既存factsから歴史・文化財の紹介を抽出。情報のない寺院に歴史を創作しない。
- 関連寺院の件数・対象・並び順を維持し、地区・宗派などの関係と読む理由を付記。
- `/readings/`: 初回3本を公開。12テーマは企画上の継続候補で、未調査の9本を自動生成して掲載しない。寺院別の関連付けは `discovery-articles.ts`。
- `/ranking/`: 共用Workerの公開済み集計結果を取得。地域別一覧とは独立。上位10件は新規ページの表示枠で、既存6件には追加しない。
- トップの既存ランダム・固定ピックアップ選出を変更せず上部へ移動。紹介文と読み物・ランキングへの入口を追加。
- 用語解説、台帳の折りたたみ、既存の台帳内アンカーへの遷移時の展開を実装。

## 計測

既存の `fgaTrack` を使用する。開発・内部アクセスの除外は既存trackerに従う。

| イベント | 意味 |
|---|---|
| temple_active_15s | 前景かつ直近60秒に操作がある閲覧時間15秒分。概算 |
| temple_photo_expand | 写真の拡大 |
| temple_reading_end | 記事・詳細の末尾への到達。読了そのものとはみなさない |
| temple_reading_open / temple_reading_next | 読み物の入口・次の記事 |
| temple_ranking_open / temple_ranking_detail | ランキング入口・寺院詳細 |
| temple_to_shrine_reading | 神社サイトへの移動。寺院サイト内滞在と分ける |

既存基盤の30分枠セッションを利用する。無操作30分で切れるセッションとの違いを公開ランキングの集計説明に明示。匿名化済みの個別履歴を一般公開せず、公開APIは寺院別集計値のみ返す。

公開後の滞在時間向上は未判定。まず基準期間・流入元・端末をそろえて比較し、15秒イベント数×15の概算時間、末尾到達、次ページ閲覧を併せて確認する。操作のない長時間読書を過少計測する場合がある。イベント導入前には同じ定義の時間がないため、導入直前の旧指標との単純比較を効果実証としない。

## 検証

`npm run check` と `node scripts/validate-discovery.mjs`。
改修前を別途ビルドした比較では、既存864ページを保持し、寺院カードを持つ147画面の一覧・関連寺院のIDと順序が一致した。
データの増減、ピックアップ6件・ヒーロー7寺院の設定、検索・ページ送りは変更しない。

ランキング基盤のテスト・修復手順は `fujigaoka-analytics-worker` のREADMEと `scripts/refresh-temple-ranking.mjs` を参照。
