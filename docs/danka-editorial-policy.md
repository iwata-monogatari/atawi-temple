# ATAWI TEMPLE 檀家向け編集方針（情報取り込みプロンプト）

- 制定日: 2026-07-12
- 位置付け: サイトの編集ミッションを定義する最上位文書。`docs/source-policy.md`（出典の信頼ランクS1〜B）と併用する。両者は補完関係にある: 本書は「何を載せるか・誰のためか」、source-policy.mdは「事実の根拠として何を採用するか」を定める。

## 0. 大前提（サイトの性格）

- **ATAWI TEMPLE は檀家（だんか）のためのサイトである。観光客向けサイトではない。**
- すべての取捨選択は「その寺院の檀家・地域住民にとって有益か」を基準に判断する。
- 目的は、檀家が自坊（じぼう）の由緒・文化・営みを知り、菩提寺との関係を深める手助けをすること。
- 基礎データは静岡県知事所轄宗教法人名簿に基づく。これと矛盾する情報は採用しない。

## 1. 情報収集の手順

対象寺院について、以下の検索を順に実行する。

1. `磐田市　寺院　{寺院名}`
2. `{寺院名}　磐田　{宗派名}`
3. `{寺院名}　磐田　歴史` / `{寺院名}　磐田　文化財`
4. `{寺院名}　磐田　年中行事` / `{寺院名}　施餓鬼` / `{寺院名}　永代供養`
5. 寺院公式サイトが見つかった場合は、サイト内の全ページ（由緒・行事・墓地・アクセス等）を確認する

## 2. 情報源の分類と取り扱いルール（A/B/C）

収集した情報源は必ず次の3分類に仕分けし、分類ごとのルールに従う。

### A. 寺院独自の情報源（最優先で取り込む）

寺院公式サイト、寺院公式ブログ、寺院公式SNS、寺報のWeb版など。

- 寺院独自のURLは必ずページに取り込む（「基本情報」欄の「寺院公式サイト」および「出典・参考資料」の「寺院公式情報」区分）。
- 由緒・行事・供養に関する記載は寺院自身の発信として最も信頼できるため、内容を要約して各セクションに反映する。
- 公式サイトの有無自体も檀家に有益な情報。「公式サイト：あり／なし（確認日）」を記録する。

### B. 信頼できる背景を持つホームページ（取り込み、出典を明記する）

磐田市公式・教育委員会、静岡県公式、文化庁（文化遺産オンライン等）、宗派の本山・宗務庁、大学・研究機関、公立図書館・博物館、新聞社・NHK等の報道機関。

- 歴史・沿革、文化財指定、地域史との関わりを取り込み、必ず出典を明記する（「出典・参考資料」の「行政・公的資料」区分）。
- 創建年、開山、文化財指定年など重要事実は出典との対応がわかる形で記載する。

### C. 民間ホームページ（精査のうえ、採用可能な情報のみ取り込む）

個人ブログ、霊場巡礼サイト、寺院紹介ポータル、まとめサイト、口コミサイト。

- そのまま転載・引用しない。精査基準: 複数の独立情報源での確認／A・Bと矛盾しないか／記事の新しさ／運営者・執筆者の素性。
- 精査を通過した情報のみ、自分の言葉で書き直して取り込む。
- 断定できない事項は「〜と伝えられる」「〜とされる」と表現し、必要なら「これから調べること」へ。
- 通過しなかった情報は取り込まない。

## 3. 檀家にとって有益な情報（積極的に収集・取り込む）

- **年中行事・法要**: 春秋彼岸会、盂蘭盆会、施餓鬼会、除夜の鐘、花まつり、開山忌など
- **供養・墓地**: 永代供養、納骨堂、墓地の有無、墓地管理
- **葬儀・法事**: 寺院公式の法要受付案内、連絡先（公開されているもののみ）
- **寺院の営み**: 法話・寺報の発信、写経会・坐禅会など檀家が参加できる活動
- **檀家組織**: 護持会・世話人会など
- **地域との関わり**: 祭礼・自治会活動・防災（避難所指定等）
- **実用情報**: 所在地、駐車場、アクセス（法事で訪れる際に必要な範囲）

見つからない場合は「これから調べること」に追加する。

## 4. 文化的要素の扱い

由緒・開山開基、本尊、文化財、庭園、地域の伝承・地域史との関わりは、**檀家が自坊の価値を知るための情報**として取り込む。視点は常に「檀家・地域の記憶の伝承」であり、「見どころ紹介」「観光案内」の文体にしない。

## 5. 取り込まない情報（観光客向け情報の排除）

- **御朱印・御朱印帳に関する一切の情報**（授与の有無、デザイン、受付時間、御朱印めぐり企画）
- **有人・無人管理に関する情報**（御朱印対応のための在寺時間、社務所・寺務所の観光対応時間）
- 拝観料・拝観時間などの観光拝観情報
- 観光モデルコース、ランキング、「映えスポット」的な紹介
- 既存ページの「御朱印」項目は削除（または非表示）とする。札所情報（遠州三十三観音等）は歴史的位置づけとして「歴史と背景」に残してよいが、巡礼スタンプ収集を促す書き方はしない。

**サイト実装への反映（2026-07-12）**: `src/pages/temples/[slug].astro` のサイドバーから「有人・無人」「御朱印」「拝観時間」を撤去し、「檀家・参拝情報」パネル（駐車場のみ）に縮小。新たに「檀家の営み・行事」セクション（`danka_info` フィールド）を新設。`TempleCard.astro`・検索結果カードの「御朱印」列は「創建・年代」に置換。

## 6. ページへの反映ルール

| 情報 | 反映先セクション |
|---|---|
| 寺院の概要・現在の営み | この寺院について |
| 由緒・沿革・札所の歴史的経緯 | 歴史と背景 |
| 文化財・仏像・庭園 | 文化財・見どころ（記述は檀家視点） |
| 行事・供養・墓地・檀家組織 | 檀家の営み・行事（`danka_info`） |
| 所在地・宗派・公式URL | 基本情報 |
| すべての出典 | 出典・参考資料（行政・公的資料／寺院公式情報／民間二次情報の3区分） |
| 未確認・要現地調査事項 | これから調べること |

### `danka_info` フィールド構造（`data/temples.json`）

```json
"danka_info": {
  "official_site": {"status": "あり", "url": "https://...", "checked_at": "2026-07-12"},
  "annual_events": [{"name": "施餓鬼会", "timing": "8月", "note": "檀家参列可"}],
  "cemetery": "永代供養墓・納骨堂の有無等",
  "organization": "護持会・世話人会等の公開情報",
  "community_role": "地域の祭礼・自治会・防災との関わり",
  "parking": "駐車場の有無（法事参列者向けの実用情報）"
}
```

## 7. 品質基準・禁止事項

- 他サイトの文章のコピー＆ペーストは禁止。すべて要約・再構成する。
- 出典のない断定は禁止。確認できない事項は「調査中」「伝承による」と明示する。
- 個人情報（住職個人の私的連絡先等、寺院が公式に公開していない情報）は掲載しない。
- 廃寺・合併等が確認された場合は、現況を正確に記載し、憶測で補わない。
- 各出典には参照日（YYYY-MM-DD）を必ず付す。

## 8. 出力形式（調査エージェント向け）

対象寺院ごとに以下を出力する。

1. 収集結果サマリー: 見つかった情報源の一覧（A/B/C分類、URL、採否と理由）
2. ページ更新案: セクションごとの追記・修正テキスト
3. 出典・参考資料の更新案: 3区分での出典リスト
4. 「これから調べること」の更新案
5. 削除提案: 御朱印など観光客向け項目が既存ページにある場合の削除箇所
