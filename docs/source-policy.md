# ATAWI TEMPLE 出典ポリシー（情報種別ごとの採用基準と信頼ランク）

- 制定日: 2026-07-11
- 位置付け: 設計書「18. 出典・脚注」を具体化する運用基準。寺院ページの加筆・改稿時は本書に従う。

## 1. 情報種別ごとの第一採用出典

| 情報 | 第一に採用する出典 | 注意点 |
|---|---|---|
| 法人格・正式名称・法人住所 | 静岡県宗教法人名簿、国税庁法人番号公表サイト | 寺院名と宗教法人名が一致しない場合がある |
| 宗派・包括関係 | 県名簿、宗派公式寺院名簿 | 古い宗派、改宗歴とは分ける |
| 文化財名・指定日・種別 | 国、県、市の文化財台帳 | 寺院の説明文より台帳を優先 |
| 創建・移転・焼失・再建 | 市史、発掘調査報告書、文化財報告書、学術論文 | 寺院公式サイトだけなら「寺伝」と表示 |
| 本尊・年中行事・御朱印 | 寺院公式、宗派公式、現地掲示 | 更新されやすいので確認日が必要 |
| 建物、石碑、樹木、境内状況 | 公的文化財資料、日付付き現地調査 | 観察できた事実だけを書く |
| 拝観、駐車場、電話、撮影可否 | 寺院公式または現地確認 | 地図口コミやまとめサイトから確定しない |
| 歴史的人物との関係 | 公文書、自治体史、史料集、研究論文 | 地域伝承とは明確に分ける |

## 2. 出典の信頼ランク

| ランク | 内容 |
|---|---|
| S1 | 法令・行政台帳・公的オープンデータ |
| S2 | 国、県、市、博物館、研究機関の解説・報告書 |
| A1 | 査読論文、自治体史、史料集、発掘調査報告書 |
| A2 | 宗派公式、寺院公式 |
| A3 | 日付・位置情報・写真を伴う現地観察 |
| B | 観光協会、地域団体、郷土研究会資料 |
| 発見専用 | Wikipedia、個人ブログ、口コミ、墓地・御朱印まとめサイト、検索結果要約 |

## 3. 運用ルール

1. **寺院公式情報は一律に低品質ではない。** 現在の行事、御朱印、連絡方法、寺院自身が伝える由緒については重要な一次情報として扱う。ただし「奈良時代に創建された」のような歴史的事実を独立して証明する資料ではないため、データ上は「寺伝」または「寺院公式による説明」として保存する。
2. **「発見専用」ランクの資料（Wikipedia・参拝情報サイト等）は公開事実の根拠にしない。** 公式資料や原資料を発見するための手掛かりとして使う。既存ページにこれらを根拠とする叙述が残っている場合は、上位ランクの出典への差し替え（降格処理）を進める。
3. 同一事実に複数ランクの出典がある場合、上位ランクを本文の根拠とし、下位は補助として残すか削除する。
4. 出典には確認日を残す（特に本尊・行事・御朱印などの変わりやすい情報）。
